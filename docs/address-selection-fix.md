# Исправление выбора адреса в редакторе ЖК

Исходная версия: 86124df. Проверка выполнена в Chromium до изменения кода на трёх разных результатах Nominatim, последовательно 1 → 2 → 3 → 1. Использовались изолированные ответы с реальными адресными ориентирами; общий JSON не изменялся.

Обработчики не подменяли индекс: значения полей и Marker.getLatLng() соответствовали именно нажатой строке. Обнаружено визуальное смещение: для первого результата координаты слоя были 57.1457736, 65.5963267, а центр нарисованного значка соответствовал примерно 57.145937385, 65.596318245 — около 18,2 м севернее при zoom=16. Причина: у значка 32×32 была привязка iconAnchor=[16,30], тогда как ориентиром служило перекрестие в центре.

Дополнительный регрессионный тест без задержек между выборами выявил влияние незавершённого начального zoom-перехода редакторской карты. Исправления:

- Круглый SVG-прицел имеет anchor=[16,16], совпадающий с видимым центром.
- Только редакторская карта использует zoomAnimation=false, markerZoomAnimation=false и неанимированные программные setView; перед выбором останавливается движение и актуализируется размер контейнера. Основная карта сохраняет своё поведение.
- Каждая кнопка хранит собственные неизменяемые lat/lon, выделяется aria-pressed/is-selected. Под выбранной строкой показываются широта и долгота.
- Поля сохраняют числовую точность ответа без принудительного округления до семи знаков.
- Ручное перемещение снимает выделение результата и подтверждение координат. Изменение адреса очищает старый список; запоздалый ответ для прежнего адреса отбрасывается.

Проверки для desktop/mobile: выбор 1, 2, 3 и снова 1; сравнение координат полей, слоя Leaflet, подписи и географически спроецированного центра SVG. Допуск визуального совмещения — менее 1 CSS px (Leaflet округляет экранную позицию до пикселя). Числовые координаты слоя совпадают с выбранным ответом. Отдельно проверено отбрасывание устаревшего ответа.

Проверенные координаты 17 ЖК, файлы общих данных, workflow сохранения и настройки безопасности не менялись. Данные в тестах используются только в локальном черновике браузера, без запуска записи в GitHub.
