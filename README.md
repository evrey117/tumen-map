# Тюмень · Город для жизни

Интерактивная карта на Leaflet 1.9.4 и настоящих тайлах OpenStreetMap: 17 ЖК, поиск, четыре независимых фильтра, карточки, свободное перемещение, масштабирование, мобильная панель, учреждения в радиусе 2 км по прямой. Без платных API и без генерации географии.

## Запуск и сборка

Node.js 22.12+ (проверено на 24.19):

```sh
npm ci
npm run dev -- --port 5173
```

`npm run build` создаёт `dist/`, пригодный для статического хостинга и GitHub Pages в подпапке. `npm run preview -- --port 4173` запускает production-сборку. Открывать через HTTP, не file://.

## Все 17 ЖК на карте

В `public/data/homes.json` сохранены координаты со ссылками на объекты OSM и временем проверки. В каталоге и на карте 17 объектов. Автоматического массового геокодирования при открытии сайта нет.

- **11 адресных совпадений OSM**: Румянский, Мотивы, Окинава, Челюскинцев 5, Futuro, Айвазовский, Прео, Фатера, Домашний, Сердце Сибири, Символ. Совпадают улица и номер здания. Принадлежность каждого здания застройщику независимо не установлена. Для «Мотивов» есть предупреждение: окружение адреса в OSM называется «ЖК Колумб».
- **Чистые пруды, Остров-сад, Плэй**: координаты одноимённых контуров ЖК; адрес конкретного дома не подтверждён.
- **Сибирский**: приблизительная точка Закалужской улицы по разрешению пользователя.
- **Добро на Доке**: 57.1669359, 65.5770521 — центр контура «ЖК Добро» в OSM (`way/1215302248`). Совпадение с проектом «Добро на Доке» и домом 18 официально не подтверждено. Использовано приблизительно по разрешению пользователя.
- **Сезоны**: 57.1023436, 65.4893493 — точка улицы Владимира Абазарова в OSM (`way/1379881426`). Это **не установленные координаты дома 5 или корпуса ЖК**, а разрешённый приблизительный ориентир по указанной улице.

Все шесть приблизительных точек отмечены предупреждениями в списке и карточках. Координаты взяты из ответов сервисов, не придуманы. Сырые ответы Nominatim сохранены в `public/data/*responses.json`.

## Социальная инфраструктура и её ограничения

Исходный Overpass-снимок: 407 записей, время базы — `2026-10-31T08:39:28Z`. Обработка вынесена в `src/places.js`.

После фильтрации на карте **134 школьных объекта, 211 дошкольных и 18 поликлиник**. Это точки учреждений/корпусов OSM, не число юридических организаций. Удалены шесть дублирующих геозаписей, сохранены ссылки на оба источника. Точка и здание объединяются только при совпадающем учреждении и расстоянии до 45 м; конфликтующие адреса и отдельные корпуса сохраняются. Также исключены запланированные, закрытые, заброшенные объекты и исследовательский институт, ошибочно помеченный школой. Безымянные объекты остаются с названием категории, что явно указывает на неполноту OSM.

**Государственные поликлиники:** у одной (ГАУЗ Городская поликлиника № 5, Депутатская, 127) публичный оператор указан в OSM. Ещё 17 номерных поликлиник включены как **кандидаты по названию**, их государственная принадлежность пока не подтверждена. В каждой карточке это написано. Частные клиники исключены. Наличие номера не превращается в утверждение о государственной форме собственности.

**Текущая работа учреждений независимо не подтверждена.** OSM, теги opening_hours/check_date и отсутствие отметки о закрытии не являются проверкой действующего статуса. Приложение предупреждает об этом и не называет учреждения подтверждённо действующими. Подробный аудит и исключения: `docs/infrastructure-audit.json`.

Для уточнения запрошены официальные сайты застройщиков и медицинских организаций, но текущий сетевой прокси отклонил их HTTP CONNECT 403. Нужные домены добавлены **в черновик**, не в действующую политику. После применения настроек требуется сверить адреса и текущую работу учреждений. До этого географический интерфейс работает, но официальный аудит данных остаётся незавершённым.

## Проверки

```sh
npm test
npm run build
# При запущенном сервере на порту 5173:
npx playwright test
node scripts/live-check.mjs
```

Unit-тесты проверяют адресное сопоставление, расстояния, 17 координат с источниками, дедупликацию, исключение закрытых/запланированных объектов, различение подтверждения оператора и кандидата. Четыре браузерных сценария проверяют поиск, карточки, слои, мобильную панель и **каждый из 17 реальных ЖК**. Для изолированных UI-тестов внешняя сеть отключена; это не проверка истинности геоданных.

`live-check.mjs` использует настоящие тайлы и сохранённые данные OSM: проверяет перемещение, фактическое изменение масштаба, все четыре фильтра, поиск и мобильную ширину. Для проверки опубликованной версии задайте `MAP_URL=https://…/tumen-map/`. Нужен `/usr/bin/chromium` (измените путь для другой машины). Отчёт и снимки — `test-results/live-*`, актуальный сохранённый отчёт — `docs/verification-2026-10-31.json`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` подготовлен с **ручным** `workflow_dispatch`, без автоматической публикации при каждом push. Он устанавливает зависимости по lockfile, выполняет unit-тесты, собирает сайт и загружает `dist/` в Pages.

После разрешённого доступа к GitHub API:

1. Сохранить код в GitHub.
2. Проверить/включить Pages с источником GitHub Actions.
3. Запустить workflow и дождаться успешного deployment.
4. Проверить полученную ссылку браузером: `MAP_URL=<адрес deployment> node scripts/live-check.mjs`.

Публикация облачного окружения сама по себе не публикует сайт. До успешного deployment и проверки URL нельзя утверждать, что публичная ссылка работает. На текущем этапе доступ к `api.github.com` и `evrey117.github.io` заблокирован политикой; разрешения сохранены в черновик настроек для применения владельцем. Публикация не выполнена.
