# Тюмень · Город для жизни

## Цены квартир из Excel — 02.11.2026

В карточках всех 17 ЖК добавлены пять категорий «Найденные цены квартир»: 67 заполнены, 18 показывают «Цена не указана». Цены относятся к исследованию от 01.11.2026, а не к гарантированному минимуму всего ЖК. Условия, площадь, европланировка, дата и ссылка конкретного предложения сохранены; подробности раскрываются в строке цены.

Источник: `data-sources/prices/Tyumen_17_ZHK_prices_2026-11-01.xlsx`. Все три листа и 104 записи источников сохранены в `public/data/price-evidence.json`; 37 архивных/неподтверждённых записей не участвуют в расчёте. Импорт проверяет точные ID, сводную таблицу и причины всех пропусков. Повторный импорт: `python scripts/import-prices.py` (нужен openpyxl 3.1.5). Он намеренно заменяет цены данными Excel; не запускайте его поверх ручных обновлений без сравнения.

«Управление ЖК» редактирует пять цен, даты, официальный сайт, площади, источники и условия. Пустая цена удаляет устаревшее значение. Общая база — прежний `public/data/residential.json`, сохранение и публикация — прежний workflow с ручным подтверждением владельца. Старые версии без `pricing` остаются допустимыми. Права и секреты не менялись.

Положение «Добро на ДОКе» пока не установлено: старая точка другого ЖК явно отмечена как недостоверная, расстояния от неё отключены. Охотская, 17 — ориентир владельца для дальнейшей сверки. По проблемным ЖК координаты не придуманы. Подробности, ограничения сети, результаты тестов и публикация: [отчёт](docs/PRICES-2026-11-02.md).

Интерактивная карта на Leaflet 1.9.4 и настоящих тайлах OpenStreetMap: 17 ЖК, поиск, пять независимых фильтров, карточки, свободное перемещение, масштабирование, мобильная панель, учреждения в радиусе 2 км по прямой. Без платных API и без генерации географии.

## Запуск и сборка

Node.js 22.12+ (проверено на 24.19):

```sh
npm ci
npm run dev -- --port 5173
```

`npm run build` создаёт `dist/`, пригодный для статического хостинга и GitHub Pages в подпапке. `npm run preview -- --port 4173` запускает production-сборку. Открывать через HTTP, не file://.

## Социальная инфраструктура и её ограничения

Исходный Overpass-снимок: 407 записей, время базы — `2026-10-31T08:39:28Z`. Обработка вынесена в `src/places.js`.

После фильтрации на карте **134 школьных объекта, 211 дошкольных и 18 поликлиник**. Это точки учреждений/корпусов OSM, не число юридических организаций. Удалены шесть дублирующих геозаписей, сохранены ссылки на оба источника. Точка и здание объединяются только при совпадающем учреждении и расстоянии до 45 м; конфликтующие адреса и отдельные корпуса сохраняются. Также исключены запланированные, закрытые, заброшенные объекты и исследовательский институт, ошибочно помеченный школой. Безымянные объекты остаются с названием категории, что явно указывает на неполноту OSM.

**Государственные поликлиники:** у одной (ГАУЗ Городская поликлиника № 5, Депутатская, 127) публичный оператор указан в OSM. Ещё 17 номерных поликлиник включены как **кандидаты по названию**, их государственная принадлежность пока не подтверждена. В каждой карточке это написано. Частные клиники исключены. Наличие номера не превращается в утверждение о государственной форме собственности.

**Текущая работа учреждений независимо не подтверждена.** OSM, теги opening_hours/check_date и отсутствие отметки о закрытии не являются проверкой действующего статуса. Приложение предупреждает об этом и не называет учреждения подтверждённо действующими. Подробный аудит и исключения: `docs/infrastructure-audit.json`.

На этапе первоначальной сверки официальные сайты застройщиков и медицинских организаций были заблокированы сетевой политикой. Позже необходимые домены были разрешены, однако независимая сверка текущей работы учреждений ещё не завершена. Географический интерфейс работает; официальный аудит данных остаётся открытым.

## Проверки

```sh
npm test
npm run build
# При запущенном сервере на порту 5173:
npx playwright test
node scripts/live-check.mjs
```

Unit-тесты проверяют адресное сопоставление, расстояния, 17 координат с источниками, дедупликацию, исключение закрытых/запланированных объектов, различение подтверждения оператора и кандидата. Шесть браузерных сценариев проверяют поиск, карточки, слои, мобильную панель и **каждый из 17 реальных ЖК**. Для изолированных UI-тестов внешняя сеть отключена; это не проверка истинности геоданных.

`live-check.mjs` использует настоящие тайлы и сохранённые данные OSM: проверяет перемещение, фактическое изменение масштаба, все пять фильтров, поиск и мобильную ширину. Для проверки опубликованной версии задайте `MAP_URL=https://…/tumen-map/`. Нужен `/usr/bin/chromium` (измените путь для другой машины). Отчёт и снимки — `test-results/live-*`, актуальный сохранённый отчёт — `docs/verification-2026-10-31.json`.

## Промышленные зоны

Новый переключаемый слой «Промзоны» использует **248 настоящих контуров landuse=industrial** из OpenStreetMap: 245 Polygon и 3 MultiPolygon, в том числе внутренний вырез. Выборка Overpass сделана по административной территории Тюмени (relation/2049854); целые исходные контуры сохранены, включая части на границе города. Кругов, буферов, исправления контуров или придуманных вершин нет. Для полного городского реестра промзон OSM может быть неполон.

Фиолетовая полупрозрачная заливка и отдельный фильтр не затрагивают 17 ЖК и социальные слои. В карточке территории: название (либо «Промышленная территория»), площадь по сферической модели Земли с учётом отверстий, landuse/industrial, оператор при наличии и ссылка на оригинал OSM. Площадь не является кадастровой.

В карточке ЖК — пять ближайших промзон по расстоянию **до границы**, а не центра. Проверяются все сегменты всех полигонов и внутренних колец; расстояния геодезические, по прямой, в метрах/километрах. Если точка ЖК внутри промышленной территории, это сообщается отдельно; расстояние до её границы остаётся фактическим, не заменяется нулём. Для приблизительной точки ЖК расстояния также помечены ориентировочными. Данные о выбросах, опасности, санитарно-защитных зонах и действующем производстве отсутствуют: промышленный landuse не является оценкой экологического воздействия.

Источники: `data-sources/industrial-overpass.json` (оригинальный ответ), `public/data/industrial.geojson` (публикуемый слой), `docs/industrial-audit.json` (аудит). Время базы OSM: 2026-10-31T12:42:51Z. Проверены замкнутость, тип Polygon/MultiPolygon, конечность координат, самопересечения, допустимость геометрии и положительная площадь. Все 248 контуров прошли проверку; каждый опубликованный узел проверен по оригинальному ответу Overpass.

Обновление вручную из корня репозитория:

```sh
python scripts/fetch-industrial.py
node scripts/prepare-industrial.mjs data-sources/industrial-overpass.json
npm test
npm run build
```

Исходный form-запрос Overpass вернул HTTP 406; поддерживаемый POST с Content-Type text/plain сработал. Скрипт сохраняет проверку TLS и наследует сессионный прокси. При неполном ответе не следует заменять опубликованный набор. Новый комплект включает 16 unit-тестов и 6 браузерных сценариев, в том числе отверстия, мультиполигоны, расстояния изнутри, фильтр и мобильный экран.

## GitHub Pages

Сайт: https://evrey117.github.io/tumen-map/ . Репозиторий уже публичный, Pages настроен на GitHub Actions; эта доработка видимость не меняет. ## Управление ЖК

Нажмите «Управление ЖК» на карте. Добавлены создание, изменение, удаление с подтверждением, геокодер, перенос метки, отмена, история и восстановление. Общие данные читаются из residential.json в main и синхронизируются между устройствами. Workflow безопасного сохранения включён владельцем слиянием PR №1; каждая запись по-прежнему требует ручного подтверждения Run workflow владельцем в GitHub. Эта визуальная доработка не меняет его права или проверки. Никакие секреты не находятся на сайте. Подробные кнопки, ограничения, модель безопасности и порядок активации — [docs/ADMIN.md](docs/ADMIN.md).

## Визуальная иерархия маркеров

По умолчанию ЖК имеют размер **33 px**, школы, детские сады и поликлиники — **21 px**. ЖК остаются насыщенно-синими с домом, белой рамкой и тенью. Инфраструктура сохраняет зелёный, оранжевый и красный цвета; её контраст усилен для различимости на подложке.

Кластеризация полностью удалена, включая зависимость Leaflet.markercluster и её стили. **Все три социальных слоя включены одновременно по умолчанию. Каждый из 363 объектов показывается отдельной меткой при любом масштабе; кругов с числами нет.** При отдалении соседние значки могут накладываться, но не группируются и не скрываются программно. Клик по метке или выбор объекта в списке «Рядом» открывает его карточку.

Настройка «Размер маркеров»: компактный 32/20 px, стандартный 33/21 px, крупный 34/22 px (ЖК/инфраструктура). Выбранный ЖК увеличивается на 20%, показывает название и карточку; при закрытии выделение снимается. На малом масштабе скрываются только текстовые подписи инфраструктуры, не её метки.

Порядок Leaflet panes сохранён: промзоны 350, инфраструктура 500, ЖК 620; управление картой выше картографических слоёв. Координаты, общий JSON, социальные объекты, промзоны, права и механизм административного сохранения не меняются.
